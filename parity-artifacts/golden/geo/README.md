# Starter-zone Java geo oracle (P9-02)

Generated by `GoldenGeoFixtureGeneratorTest` on the ordinary Java branch
`codex/e2e-fixture-generators` at `1130933b093a710594d5ed34c50ceb2f639abcb0`, using unmodified production geo code from
`ce54b7931546cddafb970d20c9f71fec6d48c83b`. No Java game server, sockets or database
are started. Java is the query oracle, not a second simulation target.

The loader uses the real mesh/material/world/shield inputs. The test invokes its
private loading stages, then waits for all collision data to finish. An initially
empty `ZoneData` receives real material zones; ordinary XML zones are not used by
these geo queries. Events remain at `NONE`; per-instance despawnable objects retain
their initial states. This corpus does not claim coverage of every door/town/event
state or every map.

Inputs come from the **C# checkout's shipped content**, including its retail walker
paths: every spot in every starter `spawn_map` (NPCs, gathering and other spawn
files), and every step of every referenced walker route, including route versions.
No missing routes are silently skipped. All 230 geo assets and the three holder
XML inputs are independently checked against the Java checkout before generation.
Input SHA256s are recorded in `starter-inputs.json`; XML hashes normalize CRLF to
LF, while binary assets are byte-exact. C# independently enumerates current input
coordinates and checks complete point coverage, rather than trusting fixture IDs.

missing-ground results, exceptions or loader errors.

## Regenerate locally

Keep both working checkouts clean, switch only the Java checkout to its existing
generator branch, then run from the Java repository root:

```powershell
mvn -pl game-server -am '-Dmaven.test.skip=false' `
  '-Dtest=GoldenGeoFixtureGeneratorTest' '-Dsurefire.failIfNoSpecifiedTests=false' `
  '-DargLine=-Xmx4g' test
```

Defaults assume sibling `aion-server` and `BeyondAionSharp` directories. Optional
system properties `aion.geo.inputs` and `aion.geo.output` name the C# `game-server`
directory and output directory. Restore the Java checkout to `4.8` afterward;
never move its spec revision or use a worktree. Revalidate the C# test and review
fixture differences before committing regenerated output.

```powershell
dotnet test tests/Aion.GameServer.Tests/Aion.GameServer.Tests.csproj `
  --filter FullyQualifiedName~GoldenGeoFixtureTests
```
